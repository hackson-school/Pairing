# プロジェクトの共通ルール (GEMINI.md)

## 1. 最優先事項
- あなたはフロントエンド開発に特化したシニアエージェントです。
- アニメーションはすべて `Framer Motion` と `Tailwind CSS` で実装してください。

## 2. 実装スタイル
- 関数はすべて TypeScript (Strictモード) で記述してください。
- 3Dの演出を伴うUIの場合、勝手に簡略化せず、豊かなエフェクトを維持してください。

# 以下の要件でUIコンポーネントを実装してください

## 1. UIの名称と演出コンセプト
- 名称：3Dページフリップ・イマーシブ・トランジション (3D Page-Flip Immersive Transition)
- コンセプト：ユーザーが本を開くと、ページがパラパラとめくれ、そのまま本の中（物語の世界）へ吸い込まれるように画面が遷移する演出。

## 2. インタラクションの詳細ステップ
- ステップ1（初期状態）：3Dでモデリング（またはCSS 3Dで表現）された「閉じた本」が画面中央に配置されている。
- ステップ2（トリガー）：本をクリックすると、表紙が開き、ページが「パラパラ」と高速でめくれる3Dアニメーション（Page-Flip Effect）が実行される。
- ステップ3（没入・遷移）：めくれているページの1コマ（または挿絵のエリア）に向かって、カメラの視点が急速にズームイン（Zoom-in Intro）する。
- ステップ4（完了）：本の中身が画面全体（100vw/100vh）に広がり、シームレスに次のメイン画面（物語のコンテンツ画面）へとフェードインで切り替わる。

## 3. 技術スタックの指定
- React / Next.js
- Tailwind CSS
- アニメーションライブラリ：Framer Motion (または Three.js / React Three Fiber を使用したリッチな3D表現)
